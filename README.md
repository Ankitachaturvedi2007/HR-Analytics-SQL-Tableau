# 📊 HR Analytics — SQL & Tableau

## 📌 Project Overview

This project focuses on analyzing employee data to understand **workforce patterns, employee attrition, job roles, demographics, job satisfaction, and other HR-related trends**.

The project combines **SQL-based data analysis** with **Tableau data visualization** to transform raw employee data into meaningful and interactive insights.

---

## 🎯 Objectives

* Analyze employee demographics and workforce distribution
* Calculate employee attrition and attrition rate
* Identify departments and job roles with higher attrition
* Analyze employee satisfaction and overtime
* Explore workforce patterns using different employee attributes
* Build an interactive HR Analytics dashboard in Tableau

---

## 🛠️ Tools & Technologies

* **MySQL** — Data analysis and SQL queries
* **Tableau** — Data visualization and dashboard development
* **Excel / CSV** — Dataset and data preparation

---

## 📊 Key Analysis

The project covers:

* Total Employees
* Active Employees
* Attrition Count
* Attrition Rate
* Average Employee Age
* Attrition by Department
* Attrition by Job Role
* Attrition by Gender
* Attrition by Education Field
* Employee Distribution by Age Group
* Job Satisfaction Analysis
* Overtime & Attrition Analysis

---

## 📈 Dashboard

An interactive **Tableau HR Analytics Dashboard** was created to present the key findings through KPIs, charts, and filters.

Users can explore the data based on different employee attributes and analyze workforce and attrition patterns interactively.
